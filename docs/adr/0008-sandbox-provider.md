# ADR-0008: Sandbox / compute provider

- Status: Open
- Spec: §17, §38, §40, §42 (Q6)

Option A: OCC Kubernetes Compute in its qualified topology. Option B: one managed sandbox (E2B is a
named candidate; OpenSandbox/Daytona alternatives). Not raw Firecracker first. Do not install several
candidates together. Selection needs Q6 evidence (processes, files, transport, pause/resume, artifacts,
egress, cost). Daytona self-host licensing is not established by the spec's review.
