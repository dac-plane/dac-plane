# Security policy

## Reporting a vulnerability

Report privately through [GitHub security advisories](https://github.com/dac-plane/dac-plane/security/advisories/new).
Do not open a public issue. Please include the affected version or image digest and how to reproduce the problem.

No response time or support objective has been established yet.

## Supported versions

Only the latest release receives fixes. See [RELEASE.md](RELEASE.md) for what a release contains and how to verify it.
